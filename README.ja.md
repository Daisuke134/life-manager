# Life Manager

**仕事、お金、日々の生活を動かす、先回り型の汎用エージェントです。**

Life Managerは、委任された権限の範囲で取り組む仕事を選び、接続したツールで実行し、実際に起きた結果を確認して報告します。目標は、最初の説明とセットアップの後は毎日の指示なしで動き続けることです。Life Managerは、実行方法の異なる一つの製品です。

> **開発状況：** Cloudの登録から確認済み収益までの一連の流れは開発中です。Capafyアカウント登録、メール確認、公開、売上の読戻し、出金、Cloud課金、公開Cloud画面のいずれも、エンドツーエンドでは確認されていません。収益は保証されません。現在のソース機能は[エージェント一覧](docs/agents.md)を確認してください。

## 一つの製品、複数の実行環境

| 実行環境 | 内容 | 現在の状況 |
|---|---|---|
| **Life Manager Cloud** | 有料・スマートフォン中心のサービスを予定しています。顧客ごとに分離されたMaritime VMでエージェントを動かし、対応する場合は登録済みメールを利用して結果を報告します。 | 収益化までの全体フローと公開Cloud画面は開発中です。 |
| **セルフホスト** | 同じビジネスコアを利用者自身の環境で動かす無料のオープンソース版です。 | ソースと導入ガイドがあります。プロバイダー設定や結果確認の要件はワークフローごとに異なります。 |
| **エージェントクライアント** | ChatGPT/Codex、Grok Bot、Muse、Dotsは、同じLife Managerを動かすための対象環境であり、別製品ではありません。 | 各環境の互換性やバックグラウンド実行は個別に検証が必要です。このリポジトリを読めるだけでは、連携が動作する証明になりません。 |

Cloudの最初の収益ワークフローはCapafyを使う想定です。有用なSkillを準備・申請し、Publisher登録条件を満たし、審査と売上の公式記録を確認します。Capafyでは正確なPublisher情報と公開サポートメールが必要で、返金不可の申請料US$0.99がかかります。公開前に自動審査と人手による審査があります。申請成功は販売を意味せず、売上も保証されません。顧客の明示的なセットアップ許可で完了できない適格性・本人確認などの手続きでは、Life Managerは停止する必要があります。

Googleログインで確認されるのは本人情報とメールアドレスです。Gmail受信箱へのアクセス権は付与されません。プロバイダーが受信箱確認を求める場合は、用途を開示したテナント専用メールボックスか、別途許可されたメール連携が必要です。

## ワークフロー

Life Managerは、仕事、収入機会、お金、予定、心身の健康、日々の行動を、一つのアクション・証跡台帳でつなぐことを目指しています。

| ワークフロー | 目指す結果 |
|---|---|
| 契約仕事 | 適した案件を探し、応募・納品し、プロバイダーの結果を照合する。 |
| モバイルアプリ | アプリを作り、公開し、改善・販売・計測する。 |
| アフィリエイト・CPA | 成果を計測できる機会を探し、配布する。 |
| 執筆 | 有料コンテンツを作成・販売し、執筆機会に対応する。 |
| デジタル商品 | プロンプト、電子書籍、スタンプなどを作り、配布する。 |
| AIサービス | 役に立つAI Skill、サブスクリプション、APIを公開する。 |
| 投資 | 明示的に設定されたリスク制限付き戦略を実行する。 |

各ワークフローには専用のプロバイダーアカウントや権限が必要で、追加費用が発生する場合があります。予定されている機能は、プロバイダーが仕事を受理した証拠や収益が発生した証拠ではありません。

## セルフホストで始める

オープンソース版はターミナルから次を実行します。

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Daisuke134/life-manager/main/scripts/bootstrap.sh)" life-manager local
```

公式Codexのログイン後、[導入ガイド](docs/getting-started.md)に沿って利用するワークフローのアカウントを接続してください。必要条件と現在の制限は[エージェント一覧](docs/agents.md)を確認してください。
