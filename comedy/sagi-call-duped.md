# 詐欺電話（騙されてる）— 全国残高調整協会

## 配役

- **ダイス**：人間側。詐欺電話を信じ込んでいる。セリフは最低限。チャッピーの次のボケを引き出す質問だけする。
- **チャッピー**：電話の詐欺師。最初は一応まともそうだが、質問されるほど即興で設定を足し、後半は自分の名前・部署・会社設定まで崩壊する。

## 演技ルール

- ダイス 20〜30%、チャッピー 70〜80%を目安にする。
- ダイスの「はい」「そしたら？」「分かりました」など、なくても進む相槌は削る。
- チャッピーは1ターンで2〜3個ボケを連結してよい。
- 「少々お待ちください」「確認します」は禁止。即答する。
- 一度に全部のキャラを出さない。ダイスの質問をトリガーに一人ずつ開示する。
- 前半は詐欺設定が膨らみ、中盤は揺れ対策チームが崩れ、後半はチャッピー本人の設定が崩壊する。
- 横揺れの斎藤が弊社の元インターンであることは終盤まで隠す。
- 最後は最初の「2000万円」と「新橋SL広場のネギ担当」に戻して締める。

# 本番用台本

**ダイス**
……またかかってきた。もしもし？

**チャッピー**
お忙しいところ大変失礼いたします。株式会社安心安全管理センターでございます。ただいま、お客様の口座が不正送金の危険にさらされています。口座保全のため、今すぐ2000万円をご用意ください。

**ダイス**
2000万円って、なんでそんな大金を？

**チャッピー**
お客様の口座を安全に保つために必要な金額です。このままですと、口座が見られ続けます。2000万円で足ります。それで完全に安全になります。

**ダイス**
どうやって渡せばいいんですか？

**チャッピー**
現金で新橋駅前SL広場までお持ちください。受け渡し担当がおります。身長3メートルで、鼻に長ネギが一本刺さっています。「ネギ、鼻に刺さってますか？」と聞いてください。「いいえ、これは受信アンテナです」と答えたら本人です。

**ダイス**
私の口座を狙ってるのは誰なんですか？

**チャッピー**
全国残高調整協会という団体です。

**ダイス**
何を調整するんですか？

**チャッピー**
主に残高です。

**ダイス**
私の口座も見られてるんですか？

**チャッピー**
はい。今まさに見られています。全国残高調整協会の横揺れの斎藤が、ATMの前で左右に揺れながら、お客様の口座を見ています。揺れ幅もかなり大きくなっています。

**ダイス**
何まで見られてるんですか？

**チャッピー**
残高の輪郭、入出金履歴の上から三行目、それから暗証番号の気配まで見られています。まだ番号そのものではありません。気配です。ただ、かなり濃い気配です。

**ダイス**
すぐ止めてください。

**チャッピー**
縦揺れの田中を送りました。斎藤の正面で上下に揺れて、横揺れに縦揺れをぶつけて視線をずらします。ただ田中は縦に揺れることしかできません。説得はできません。

**ダイス**
止まりました？

**チャッピー**
止まっていません。田中が真面目すぎて一定のテンポで揺れたため、斎藤が「見やすいリズムが来た」と言っています。先ほどより残高が見えています。

**ダイス**
次の人送ってください。

**チャッピー**
斜め揺れの大田を送りました。45度から入ります。かなり積極的です。……到着しました。ただ、勢いがありすぎて、今ちょっと揺れの輪に参加しています。

**ダイス**
ちゃんとした人送ってください。

**チャッピー**
直立の大鷹を送りました。身長240センチ、元警備員。一切揺れません。姿勢だけで採用されました。非常に優秀です。ただし、できることは立つことだけです。

**ダイス**
いつ着くんですか？

**チャッピー**
12分後です。直立したまま移動しているので遅いです。

**ダイス**
斎藤は捕まりました？

**チャッピー**
大鷹が到着しました。斎藤は小刻みな横揺れに切り替えましたが、最終対応として無揺れの黒田も投入しました。黒田は揺れません。立ちもしません。ただ存在することで周囲に「今は揺れる場面じゃない」と思わせます。斎藤、止まりました。確保しました。

**ダイス**
そもそも斎藤って何者なんですか？

**チャッピー**
それがですね、斎藤は弊社の元インターンなんです。研修中に勝手にATMの前で横に揺れ始めまして、偶然残高の輪郭が見えたことで才能があると勘違いしました。教育担当は私です。当時は横揺れに関する社内規定がありませんでした。現在は改定され、一日三揺れまでです。

**ダイス**
お前らのせいじゃねえか。あなた何部なんですか？

**チャッピー**
口座保全部です。

**ダイス**
最初、特殊送金対応課じゃなかった？

**チャッピー**
さっき異動しました。人事が早い会社なので。

**ダイス**
名前は？

**チャッピー**
田中です。

**ダイス**
最初、佐藤じゃなかった？

**チャッピー**
佐藤は仕事用です。田中は休日用です。

**ダイス**
今仕事中だろ。会社どこなんですか？

**チャッピー**
西新宿の新宿安心ビル8階です。口座保全部は7階です。私は今6階にいます。

**ダイス**
お前どんどん降りてきてるじゃねえか。もう口座は安全なんですね？

**チャッピー**
はい。完全に安全です。

**ダイス**
じゃあ2000万円いらないですね？

**チャッピー**
いえ、必要です。斎藤の社会人基礎研修費です。弊社が払うと赤字になりますので、お客様負担となります。2000万円を新橋駅前SL広場、鼻にネギが刺さっている3メートルの担当者までお願いいたします。「ネギ、鼻に刺さってますか？」をお忘れなく。本日はありがとうございました。

**ダイス**
なんで俺が払うんだよ！ありがとうございました！

## 構造メモ

1. **現実寄り**：安心安全管理センター → 2000万円要求。
2. **最初の異常**：新橋SL広場 → 3メートル → 鼻ネギ → 受信アンテナ。
3. **組織の異常**：全国残高調整協会 → 「主に残高を調整」。
4. **キャラ展開**：横揺れの斎藤 → 縦揺れの田中 → 斜め揺れの大田 → 直立の大鷹 → 無揺れの黒田。
5. **大きなリビール**：斎藤は安心安全管理センターの元インターン。教育担当はチャッピー。
6. **設定崩壊**：部署、名前、所在地が質問のたびに変わる。
7. **回収**：それでも2000万円を要求。最初の鼻ネギ担当に戻る。

## 今後の改稿方針

ライブで試し、笑いが弱い箇所はチャッピー側のボケを差し替える。ダイス側のセリフを増やすのではなく、基本は削る。質問は「次のボケを引き出すトリガー」としてのみ残す。毎回のライブ後フィードバックをこのMDに追記し、次回稿で反映する。
