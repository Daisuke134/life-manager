# コント「安心安全管理センター」— 現行基準稿

> Canonical as of 2026-09-13.
>
> **僕 = 人間側（ユーザー）。最後まで基本的に騙されていて、疑うためではなく助かるために質問する。**
> **君 = 電話をかけてくる男（詐欺師）。真面目な口調で、説明するほど世界設定がおかしくなる。**
>
> 旧「フニャフニャ財団」は、現行では **全国口座観測協会** に変更。

## 完全原稿

**君**  
お忙しいところ大変失礼いたします。株式会社安心安全管理センターでございます。ただいま、お客様の口座が不正送金の危険にさらされています。口座保全のため、今すぐ2000万円をご用意ください。

**僕**  
え、2000万円って、なんでそんな大金を？

**君**  
はい。お客様の口座を安全に保つために必要な金額です。このままですと、口座が見られ続けます。

**僕**  
それは2000万円払えば安全になるんですか？

**君**  
はい。2000万円で足ります。それで口座は安全になります。

**僕**  
私の口座を狙っているのは、どういう存在なんですか？

**君**  
はい。お客様を狙っているのは、全国口座観測協会という団体です。表向きは地域清掃ボランティアですが、実態は全国の口座を遠くから見ている組織です。実際はほぼLINEグループです。

**僕**  
それは私の口座ももう見られてるってことなんですか？

**君**  
はい、見られています。今、全国口座観測協会の横揺れの斎藤が、ATMの前でお客様の口座を見ています。かなり横に揺れながら見ています。揺れ幅が大きくなっていますので、非常に危険です。

**僕**  
横揺れの斎藤って、誰なんですか？

**君**  
横揺れの斎藤は生まれた時から少し横に揺れていた人物です。普通、赤ちゃんって泣くじゃないですか？ 斎藤は泣く前にまず横に揺れたそうです。学生時代も授業中ずっと横に揺れていて、先生から「落ち着きなさい」ではなく「一回、縦になりなさい」と言われていました。それで、大人になってATMの前に立った時、横に揺れると人の口座の残高の輪郭が見えることに気づいてしまったんです。それ以来、ATMの前でお客様の口座を見ています。

**僕**  
もうどのくらい見られちゃってるんですか？

**君**  
かなり見られています。残高の輪郭、入出金履歴の上から三行目あたり、暗証番号の気配の入口くらいまで。ただ、まだ完全ではありません。今なら止められます。

**僕**  
そいつを止めてください。すぐに止めてください。

**君**  
手配しました。今、横揺れの斎藤を止めるために縦揺れの田中を向かわせました。

**僕**  
その縦揺れの田中は何をしてくれるんですか？ どういう人なんですか？

**君**  
縦揺れの田中は、こちらが出す揺れ対策専門の担当者です。田中が正面に立って縦に揺れることで、斎藤の視線をずらします。ただ田中は縦に揺れることしかできません。説得はできません。

**僕**  
田中はやってるんですか？ 仕事を。

**君**  
田中はやっています。ただ、真面目すぎて縦に揺れすぎていまして、そのせいで斎藤は見やすいリズムが来たと思って、さらに見ています。

**僕**  
すぐに対応してください。次の担当者を送ってください。

**君**  
手配しました。次の担当者として、斜め揺れの大田を向かわせました。大田は積極的です。ただ今、勢いが強すぎて揺れの現場に参加し始めています。

**僕**  
じゃあ次の人も送ってください。

**君**  
手配しました。次の担当者として、直立の大鷹を向かわせました。大鷹は一切揺れません。ただ、直立したまま移動しているので、到着まで約十二分かかります。元警備会社員で、姿勢だけで採用されました。優秀です。ただし、できることは立つことだけです。

**僕**  
そうですか。直立の大鷹、三人がかりで捕らえられましたか？

**君**  
三人がかりで囲むところまでは成功しました。ただ、斎藤が小刻みに細かく揺れ続けていて、完全には止まっていません。そこで最終対応として、無揺れの黒田を派遣しました。黒田は揺れません。立ちもしません。ただ存在だけで揺れをやめさせる人間です。今、到着しました。横揺れの斎藤は止まりました。

**僕**  
じゃあもう捕らえてください。そもそも横揺れの斎藤はなんでそんなことするんですか？

**君**  
はい、捕らえました。横揺れの斎藤は、弊社の元インターンでした。研修中に勝手に揺れ始め、偶然見えてしまったことを勘違いしたまま名乗り続けていました。現在は厳重注意のうえ、社会人基礎研修に差し戻しています。

**僕**  
じゃあ私の口座は安全なんですね？

**君**  
はい、安全です。

**僕**  
じゃあもう2000万円も必要ないんですね。

**君**  
いえ、必要です。安全になった口座を安全なままにしておく費用として2000万円が必要です。では、2000万円を新橋駅前SL広場までお持ちください。本日はありがとうございました。

## 現行の演技ルール

- 僕は詐欺を見破ろうとしない。最後まで基本的に信じて、切迫して助けを求める。
- 僕の質問は「疑い」ではなく「助かるための確認」。質問で君の次のボケを引き出す。
- 君は男。電話の詐欺師役。
- 君はAIっぽくしゃべらず、実在する変な電話担当者として自然に話す。
- 「少々お待ちください」「確認します」は原則使わず、即答する。
- 僕のセリフは最小限、君のセリフ・ボケ密度を高くする。
- 一度にキャラを全部出さない。横揺れ→縦揺れ→斜め揺れ→直立→無揺れと質問に応じて開示する。
- 「横揺れの斎藤 = 弊社の元インターン」は後半のリビールとして残す。
- 今後は、後半ほど部署・名前・所属などが短く変わり、質問されるほど君の設定が崩壊する方向を強める。
- 長い部署名を何度も復唱しない。情報説明ではなく、矛盾そのものを笑いにする。
- ラストの「もういいよ」の前に、もう一段大きい展開を置く余地を残す。
