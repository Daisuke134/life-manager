# VAEで人口を作る：属性の組み合わせをデータから学ぶ

調査日：2026年10月17日。人口合成の入門講座。基本、論文ごとの工夫、読んだコードを区別する。

## 属性の組み合わせを学ぶ

年齢、就業、所得などを持つ仮想の住民を作りたい。IPFは初期表の値を既知の集計に合わせる。ベイジアンネットワークは依存関係と局所的な確率分布から全体を表す。今回のVAEは、ニューラルネットワークで属性の組み合わせの分布を学ぶ方法である。三つだけで人口合成の全方式を網羅するわけではない。人口の生成と、生成した人の反応を予測する工程も別である。

## 1. 学習とは何をすることか

例えば調査データの一行に「35歳・就業・所得区分B・4人世帯」が入っている。多数の行から、どんな属性が一緒に現れやすいかをモデルに学ばせる。ここでいう学習は、モデル内部の数値を少しずつ変更し、目的関数を小さくする作業である。人口を代表する重みと、この内部パラメータは別物だ。

VAEはVariational Autoencoder、変分オートエンコーダの略である。KingmaとWellingの原論文が基礎になる。一般的な生成モデルの一種で、LLMを必要としない。

## 2. 符号化器と復号器

まず、普通のオートエンコーダを考える。符号化器（encoder）は一行の属性を内部表現に変える。復号器（decoder）はそこから元の属性を再現する。料理でたとえるなら、多数の料理の特徴を短い内部メモで表し、そのメモから料理を再現する練習に近い。ただしモデルのメモは、人間に読める説明とは限らない。

VAEでは、典型的には符号化器が潜在変数の正規分布の平均とばらつきを出力する。その分布から値を抽選して復号器へ渡す。潜在変数（latent variable）とは、記録に直接入っていない内部の変数のことだ。軸の一つが必ず年齢、もう一つが所得、と解釈できるわけではない。名前の「変分」は、直接計算しにくい潜在変数の事後分布を、計算しやすい分布で近似する考え方を指す。

学習時は「観測記録→符号化器→その記録に対応した潜在分布から抽選→復号器→再現結果」。新規生成時は「事前分布から抽選→学習済み復号器→新しい記録」。新しい人を生成するたびに実在の誰かの入力記録が必要なわけではない。

## 3. 二つの学習目標

一つ目は再構成誤差を小さくすること。年齢や就業状態などを、元の記録に近く再現する。カテゴリーなら正解カテゴリーに高い確率を置くようにする。数値とカテゴリーの扱いは実装で異なる。

二つ目は、符号化器の分布が事前分布から離れすぎないようにすること。標準的な例では事前分布を標準正規分布にする。この調整にKLダイバージェンスという量を使う。これは一般の距離のように対称ではない。二つの分布の違いを測る量として、まず理解すればよい。

最小化する目的は概略として「再構成の損失＋KLの項」。再現だけを重視しても、事前分布から生成するときにうまくいくとは限らない。反対にKLばかりを重視すれば、属性の情報をうまく表せなくなることがある。重みや構造、学習状態の確認が必要になる。

対角正規分布の代表例では、抽選は `z = mu + sigma * epsilon` と書ける。epsilonは標準正規分布から引く。この書き換えは再パラメータ化（reparameterization）と呼ばれ、抽選を含むモデルで勾配を使って学習するために重要になる。muは平均、sigmaは標準偏差で、分散はsigmaの二乗。

## 4. 何が生成されるのか

生成されるのは「28歳・非就業・所得区分A」のような記録である。それは新しい観測結果ではない。元の標本にない組み合わせを出せても、その組み合わせが現実に存在する証拠にはならない。定義上の矛盾も自動で防げるとは限らない。

復号器が各属性のカテゴリー確率を出す設計もある。その確率をどう記録へ変えるかは実装ごとに確認する。全ての実装が同じ抽選手順を採るわけではない。ニューラルネットワークを使えば少数派の分布が必ず正しくなる、という保証もない。

## 5. 実際の研究は何をしたか

### Borysov・Rich・Pereira（2019）

デンマークの交通調査を使い、VAEとGibbs sampling、ベイジアンネットワークを比較した。低次元では比較手法の方がよく、多数の属性を扱う場合にVAEの利点を検討している。したがって「新しいから常に高精度」とは読めない。VAEのモデルで候補人口を作り、地域の目標集計へ合わせる調整は別の工程として考えられる。生成とIPFは必ずしも排他的ではない。[1]

### Kim・Bansal（2023）と公開PopSynth

人口合成で、実現可能性と多様性の両方を扱う研究。公開リポジトリのVAEノートブックでは、再構成とKLに加え、標本とのHamming距離に基づく項が実装されている。単純に訓練行を複製するだけでも、でたらめに新しい組み合わせを増やすだけでも十分ではない、という課題を考える材料になる。コードの距離指標を現実での実現可能性の完全な判定と同一視しない。[2]

### Sanéほか（2025）

世帯と同居する個人を一緒に表現するVAEを比較。単一モデルのSVAE-Pop2は人数の違いを空き枠でそろえ、MVAE-Pop2は世帯人数別にモデルを分ける。下図の空き枠は人として数えない。個人だけを独立に作ったときに起こり得る、世帯人数と同居人の不整合を考える重要な事例。論文の対象、人数上限、評価条件を超えて優劣を一般化しない。今回、著者の実装コードは確認できていない。[3]

## 6. 公開コードの処理

`Eui-Jin/PopSynth` の `VAE_OOSDivH_SampleCode.ipynb`。`build_VAE` は平均と対数分散を出す符号化器、抽選、属性ごとのsoftmax出力を持つ復号器を組み立てる。`vae_loss` は再構成、KL、Hamming距離の項を足す。生成用モデルは復号器を再利用し、標準正規分布の乱数を受け取る。`generate_images` という関数名だが、この用途での出力は人口属性であり画像ではない。

処理の中心を説明用に短くすると以下になる。これは実行済みの完全な学習コードではない。

```python
mu, log_variance = encoder(records)
sigma = exp(log_variance / 2)
z = mu + sigma * standard_normal()
reconstructed = decoder(z)
# 再構成とKLなどの損失でモデルを更新
# 学習後の生成は decoder(standard_normal(...))
```

比較読解として `sdv-dev/CTGAN` の `ctgan/synthesizers/tvae.py` も確認した。これは汎用表形式データ向けTVAEであり、Borysov論文の著者実装ではない。取得版のLICENSEはBusiness Source License 1.1。公開されていることを、無制限に商用再利用できることと取り違えない。PopSynthのコードはMITだが、付属データの権利・利用条件は別途確認する。今回いずれのモデルも学習・生成実行はしていない。

## 7. 人口としてどう評価するか

訓練前に、未使用の評価資料と比較条件を決める。学習・調整に使った年齢合計だけでなく、使わなかった年齢×就業×所得などの交差分布を比べる。同じ基礎資料と対象人口で単純法、IPF、BN、VAE等を比較する。各方式の入力要求が違う場合は、その差も報告する。

数える項目は、集計の誤差、未使用の組み合わせの誤差、構造的な矛盾、希少な集団の被覆、元記録の複製、費用・時間。複数の乱数設定での変動も見る。生成データの公開は匿名性の保証にならず、プライバシー評価も必要になる。分布を再現できても、政策変更の因果効果を予測できる証明にはならない。

## 8. 他の方式と比較するとき

GAN・拡散モデル、LLMによる人口生成と比較する際は、学習と生成の仕組みを分ける。世帯構造、欠測、希少な組み合わせ、条件付け、評価、プライバシー、地域や時点が変わるときの検証まで扱う。論文を読んだこと、コードを読んだこと、実行したこと、結果を再現したことを分ける。
