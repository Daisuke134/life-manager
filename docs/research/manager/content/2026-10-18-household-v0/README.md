## 6枚の話す順番

1. **何を作ったか。** 8Aの人口表に加え、世帯と個人の所属を持つ一覧を作った。実測は20,182世帯の見本から441,570世帯・1,042,763人。
2. **なぜ世帯を丸ごと使うか。** 架空の3人世帯を2組なら2世帯6人。3人から2人だけを抜く意味ではない。元の所属と続柄を保つ。
3. **何を調整したか。** WGTPを出発点に、世帯種別と人数構成の合計へ合わせる。小数の重みはTRSで整数へ。個人用PWGTPとは区別する。
4. **どれだけ近づいたか。** 整数化後の6区分TVDは0.002339から0.000544。単一州の、この区分での比較。一般的な優越ではない。
5. **何が残ったか。** 総世帯数は一致し、CSV再読で欠員など0。ただし周辺集計に最大17世帯、個人分布にも差がある。
6. **何につながるか。** 次は状況を与えた行動予測。使命は技術で苦しみを減らすことだが、その効果は今回測っていない。

## 投稿文の原稿

公開統計とPUMSの世帯見本から、44万1,570世帯・104万2,763人の仮想人口を作りました。世帯を丸ごと選び、全員の所属を保って新IDを付けています。調整で世帯構成のずれは小さくなりましたが、整数化後の集計には最大17世帯の差が残りました。コード・再実行手順・失敗し得る点も保存しています。今回は人口部品の検証で、行動や介入効果はこれからです。
