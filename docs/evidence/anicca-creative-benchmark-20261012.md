## First original Anicca carousel draft

Borrow the four-card sequence, not ThinkUp's photos, text, or exact design. Use original imagery and Anicca's existing daily-reminder feature.

1. Cover: “When it feels like everyone else is ahead” — original lifestyle image, large readable headline, swipe cue.
2. “I can move at my own pace.” Supporting line: “My path does not need to look like anyone else's.”
3. “Small steps still count.” Supporting line: “Quiet progress is still progress.”
4. “I can begin again today.” Supporting line: “One gentle choice is enough for now.”

Caption draft: “Choose one line to carry into the week. Save it for a difficult morning or send it to someone who could use a softer start. Set a daily reminder in Anicca — link in bio.”
