# Manager official website redesign preview

This directory owns the English/Japanese design source, styles, and vector illustration. It is a local proposal for aniccaai.com, not a deployed replacement. Product vision: a Manager for the universe and all living beings. Source-page research links lead to repository-owned article Markdown.

The delivered preview at `/workspace/artifacts/manager-website/` embeds CSS/SVG and replaces research links with the saved article PDFs. Its ZIP includes both standalone HTML pages and PDFs. Desktop/mobile screenshots were rendered with Chromium. No external fonts, tracking, signup, credentials or deployment are introduced.

Publishing requires applying this copy/design to the existing official landing source and checking its hosting/build configuration. The canonical repository/source-boundary contract still applies.
