# 人口v0の処理と結果

## 入力と出力

米国CensusのACS 2024 5-year Detailed Table B17001を使った。期間は2020–2024。対象は「貧困状態を判定できる人口」で、一般の全人口とは一致しない。貧困基準未満/以上と、18歳未満/18–64歳/65歳以上の組み合わせを6セルにまとめた。

1. `fetch-acs` は公式Summary Fileから50州・DC・PRの52行を抽出する。表・ヘッダー・地域集合・必要な推計値を検証する。サイズ上限8MiBまたは不完全な取得で失敗し、成功manifestを残さない。
2. `prepare-population` はPRを対象外にし、開発6州/検証4州/最終評価41地域へ固定分割する。開発6州の6セルの合計がIPFの初期表となる。復元用には各地域の年齢別人数と貧困状態別人数だけを書き出す。交差集計は採点用ファイルへ分離する。
3. `reconstruct` は初期表と周辺集計だけを読む。単純独立法は年齢と貧困状態の独立を仮定した積、IPFは初期表の関連を残して対象地域の周辺集計に合わせる。参照表を指定する引数はない。
4. `score-population` は両方式の全51地域を要求し、採点用の6セルと比較する。出典・分割・設定・ソースコード・依存バージョン・入力と出力のハッシュを照合する。レポートは開発/検証/最終評価を分ける。

公式配布先は https://www2.census.gov/programs-surveys/acs/summary_file/2024/table-based-SF/data/5YRData/acsdt5y2024-b17001.dat 。属性定義は https://api.census.gov/data/2024/acs/acs5/groups/B17001.json 。推計誤差の原列も保存するが、相関を無視してMOEを足した信頼区間は作らない。取得した州抽出のSHA256は `316b602beb75129605d91ca7a9c440a37df7bc9c02271d86d3eb39cf25559a9d`。元の配布ファイル全体のhashではない。

## 数値計算と検査

IPFには固定した `ipfn==1.4.4` のNumPy backendを改変せず使う。最大1000反復、周辺集計の最大絶対残差を対象人口で割った値が `1e-10` 以下であることを独立に確認する。今回の最大残差は約 `1.29e-11`。初期表の0セルを微小値へ置換せず、対象の0行/列はsolverから外して計算後に戻す。未収束は成功結果にしない。

TVD（全変動距離）は、6セルをそれぞれ地域の対象人口で割り、構成比の絶対差の合計を半分にした値。TVD=0.01は6区分の配分を全体の約1%分移すと一致する差に相当するが、特定の個人を1%誤分類したという意味ではない。最大セル誤差は地域全体を分母にするパーセントポイント（pp）。年齢別貧困率の誤差は、その年齢群だけを分母にしたppで、0人の群は不明（null）とする。

地域平均は地域を等しく数える。人口加重平均は人口の多い地域の寄与が大きくなる。これらと最大値を別々に報告する。地域を無作為抽出していないため、全国への一般化信頼区間を出さない。seedの作成に使った開発地域を、学習外の評価成績に混ぜない。

## 実測が示したこと

最終評価41地域の平均TVDは単純独立法0.014348、IPF0.008881。約38.1%の相対低下だった。IPFは29地域で改善し、12地域で悪化した。例えばUtah（FIPS49）では0.002432から0.012673へ悪化しており、開発地域の関連を移すことが常に有利とは限らない。評価を見て初期表や設定を変更していない。

全51地域×2方式を生成し、同じoffline入力で再実行した予測ファイルがbytesまで一致することを確認した。追加の有料モデル呼び出しは0。ある1回の復元コマンドでは単純法約0.008秒、IPF約0.037秒だった。これはこの小さなCPU実験の計測で、初回import・データ取得を除き、一般的な性能や計算費用の比較を意味しない。

数値を確認するための[公開用の集計記録](../../../docs/research/manager/evidence/2026-10-18/population-v0-summary.json)を保存した。rawデータ、全予測、完全なrun metadataはGit外に置き、コードから再生成できる。

## マネージャーへの接続

今回の成果はPopulation/Evidence/Evaluatorの最初の実装である。次の世帯部品ではACS PUMSの住宅・個人記録を世帯IDで結び、世帯を丸ごと選んだ整数化と、前後の集計誤差を扱う。その後に、状況と属性から行動を予測するモデルを、別の行動観測で学習・評価する。人口が作れたことで行動の正しさが自動的に得られるわけではない。

BN、VAE、GAN、拡散モデル、LLMによる人口生成を今回同じ条件で実行したとはしない。またAaruやSimileの内部モデルを再現した実装ではない。小さな透明な比較を先に作り、追加方式を同じ評価に接続できる形にした。すべての生命と宇宙を対象に苦しみを減らす使命に向け、今回は人間集団の構成を検査できる一部品を作った段階である。行動予測・政策比較・実行・実地成果の4段階はすべて `not_run` としている。
