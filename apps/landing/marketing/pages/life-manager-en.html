Life Manager · A proactive general agent

Your life.
A manager that takes initiative.

Life Manager is one proactive manager for work, money, everyday responsibilities, body, and mind. It chooses useful priorities, carries work forward, and verifies results without a new daily prompt. Its first Cloud earning workflow is being connected to Capafy. Run the same open-source core locally or use Life Manager Cloud from your phone on a dedicated cloud VM. Google sign-in is the web starting point and verifies identity only. No Calendar, Gmail inbox, task prompt, goal, budget, or payout details are required at signup. Calendar can be connected later only when a task needs it. Capafy requires Publisher Certification before the first Skill can publish; payout details can be added after certification. Work and results are designed to be verified and reported to your sign-in email. The complete Cloud-to-Capafy result path is still being verified. Earnings are not guaranteed.

Questions

What can you delegate?

Do I need to prompt it every day?

No task, goal, budget, or daily prompt is required to start the earning workflow. The manager chooses work and priorities. Provider-specific identity verification, account connections, and interviews may still require your involvement.

Is this more than a travel-time assistant?

Calendar travel-time management is one feature. Life Manager is being built as a general agent for your body, mind, and money.

Where can I check what is implemented?

The README and code are public on GitHub. Some capabilities require setup or are still being developed.
