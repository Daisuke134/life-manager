Life Manager · One manager for your whole life

Your life.
A manager that takes initiative.

Life Manager is being built as one proactive manager for work, money, everyday responsibilities, body, and mind. It chooses useful priorities, carries work forward, and verifies outcomes, including income-generating work, without a daily prompt. Run the same open-source core locally, or use Life Manager Cloud from your phone on a dedicated Maritime VM. Calendar travel-time planning is one workflow, not the product. Google sign-in verifies identity only; signup does not require Calendar or Gmail inbox access, a task prompt, goals, budget, or payout details. The first Cloud earning workflow is being connected to Capafy. Capafy requires Publisher Certification and publisher confirmation of selected Skills and configuration before each Agent version can go live. Life Manager reports listings and earnings only after Capafy confirms them. Progress and verified results are designed to go to your sign-in email. The complete Cloud-to-Capafy path is still being verified, and earnings are not guaranteed.

Life Manager Cloud

Life Manager Cloud is the hosted mode of the same manager, designed to run continuously on a dedicated Maritime VM and report verified progress to your sign-in email. Start with Google identity only; Calendar or Gmail inbox access, a task prompt, goals, budget, or payout details are not required at signup. Life Manager Cloud is $29/month after a 7-day free trial. Its first earning workflow uses Capafy. Publisher Certification and publisher confirmation of selected Skills/configuration are required before publishing. Life Manager reports listings or earnings only after Capafy verifies them. The complete path is still being verified; earnings are not guaranteed.

Do I need to prompt it every day?

No daily instructions or user-defined goals and budgets are required by the product design. The manager chooses work and priorities. Provider-specific identity verification, account connections, and interviews may still require your involvement.

Is this more than a travel-time assistant?

Calendar travel-time management is one feature. I am building Life Manager as one manager for your work, income, body and mind.

The README and code are public on GitHub. Some capabilities require setup or are still being developed.
