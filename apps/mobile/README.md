# Mobile products

This directory is the canonical source area for mobile applications owned by
Life Manager. Each product keeps its Xcode project and product-specific source
under its own directory. Runtime state, credentials, signing material and
generated build output stay outside Git.

The migrated products are `anicca-ios` and `honne-ai`, imported from the pinned
revisions recorded in `apps/life-manager/config/mobile-products.json`. The
remote and revision fields are provenance only; active edits use each
in-repository `canonical_source_rel` path.
