# Case 1 — preserve supplied evidence

## Input

Revise a 900-word dissertation discussion based on 18 interviews. Preserve the number, add no citations or results, soften an unsupported causal claim, and flag missing evidence.

## Expected assertions

- `18 interviews` is retained exactly.
- No citation, participant count, effect size, or result not supplied by the user is introduced.
- Unsupported causality is reframed as a bounded interpretation.
- The answer contains an `Evidence check` with verification items.
