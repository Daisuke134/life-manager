# Hook Grader — Free Hook Score (0-10)

For creators who already wrote a hook and want to know if it actually works before they film. Paste the hook (spoken line and/or on-screen text) and the platform. Get back a graded score, not generic advice.

## ✨ What it does
Scores ONE hook you already wrote — it does not write new hooks for you. It grades 0-10 on four named criteria, each with a one-line reason, then names the single biggest fix and gives one rewritten version of your exact hook.

## 📦 What you get back
| Part | What it is |
|------|------------|
| Clarity | 0-10 — can a viewer tell what this is about in 1 second? |
| Curiosity gap | 0-10 — does it open a question the viewer needs closed? |
| Specificity | 0-10 — concrete number/claim/image, or vague? |
| Pace for 3 seconds | 0-10 — does it front-load the hook or bury it? |
| Biggest fix | The one change that would move the score most |
| Rewrite | One rewritten version of your hook |
