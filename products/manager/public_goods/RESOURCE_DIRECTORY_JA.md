# Official Public Support Directory — 日本の公式支援情報への入口

*Manager / Anicca — 2026年10月21日に公式出典を確認した、無料・公開のリンク案内です。*

仕事や生活費、気持ちのつらさ、健康づくりの情報を探すときに、**公的機関が管理する既存の案内**へ直接進めるよう、確認済みの入口を分野別に並べています。このページでは問い合わせ内容や個人情報を収集しません。特定の制度の利用資格や診断、助成額、健康改善は判定しません。

## FINANCIAL — 生活費・仕事・家計の困りごと

- **生活に困っているときの制度**：厚生労働省の [生活困窮者自立支援制度](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000059425.html)。仕事・住まい・家計の相談や支援制度について、一次情報をご確認ください。
- **暮らしと家計の相談**：[厚生労働省 各種相談窓口・融資・給付制度等](https://www.mhlw.go.jp/stf/newpage_08152.html)。制度の対象、最新の窓口、提供条件は運営元が判断します。
- **借入や多重債務について**：[金融庁 多重債務者対策・相談窓口](https://www.fsa.go.jp/policy/kashikin/)。特定商品の勧誘や投資判断の代行は行いません。

## MENTAL — つらさ・不安・こころの相談

- **相談方法を選びたいとき**：厚生労働省の [まもろうよ こころ — 困った時の相談方法・窓口](https://www.mhlw.go.jp/mamorouyokokoro/soudan/)。電話、SNS、地域別の相談先は公式サイトで最新情報をご確認ください。
- ここに掲載する情報は診断・治療や緊急時の医療対応に代わるものではありません。差し迫った危険がある場合は、利用できる地域の緊急サービスに直接相談してください。

## PHYSICAL — 身体活動・健康に関する公的情報

- **身体活動・運動の基礎**：[厚生労働省 e-ヘルスネット — 身体活動・運動](https://kennet.mhlw.go.jp/information/information/exercise)。一般的な運動の考え方、安全上の注意、年齢等に応じた推奨資料への公式入口です。
- けが、持病、痛み、急な症状がある場合、このページで個別の運動処方は行いません。必要な専門家・公的窓口に直接確認してください。

## What Manager actually measured

**Public artifact:** 公的機関への入口となる、このGitHub上の公開ドキュメントの存在と可読性を外部のGitHub公開APIで確認します。これは実際のインターネット上の公開状態であり、架空のシミュレーションではありません。

**NO_ACTION:** 利用者へ無断でメールやDMを送ったり、金融取引を始めたり、健康状態を推測したりしません。表示された案内を使うかどうかは利用者自身が選びます。

**Beneficiary outcomes: NOT_MEASURED.** 資源を得られた人数、財政的困窮、精神的なつらさ、身体機能の改善、医療効果はいずれもまだ測定されていません。公開と閲覧は因果的な苦痛軽減の証明ではありません。

**Data practice:** 外部から取得した個人の相談内容・閲覧記録・健康情報・所得情報をGitHubに保存しません。この案内は紹介先の内容を再配布せず、短い独自の説明と公式リンクで構成します。リンク切れ・制度変更時は公式ページを優先してください。
