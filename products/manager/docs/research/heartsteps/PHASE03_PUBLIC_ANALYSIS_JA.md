# Manager Phase 03 — HeartSteps 公開CSVによる再現可能な代替解析

**2026-10-21 / 研究成果の範囲: 公開データの探索的再解析（2019年論文の完全再現ではない）**

## 結論

ユーザーの明示指示により **H005（元論文と同一の7,540/6,061件の選別）を waived/skipped** にし、非同一サンプルでの事前明示した分析を進めた。論文の数値へ恣意的に合わせず、公開CSVから再構成した観測比較と、参加者内相関を考慮する統計モデルを実行した。科学的な差異を残したまま次のPhaseに進む。

これは、「2019年のRCTが完全に再現できた」「Managerが人の健康を改善した」という意味ではない。

## この代替解析の対象定義

`avail=true`、実送信`send`が既知、活動の型が一意、`decision.index.nogap`が有効、前後の歩数（欠測ゼロ補完された列）が非負の判断時点だけを対象とする。論文と一致しない研究日を決め打ちせず、**日数に基づく除外を行わない**。時間変化の検討には`decision.index.nogap`という**順序指数**を使い、論文の`study.day.nogap`とは呼ばない。対象は6,330判断・37人。元論文では6,061の利用可能な判断時点を解析した。

## なぜ元論文の完全再現をスキップしたか（H005）

- 公開`csv`の研究日と著者の内部RData分析用`study.day.nogap`の対応が不完全。
- `floor(decision.index.nogap/5)`という以前の代用法は、公開された歩数側の研究日情報と数千件単位で相違。
- 公開Jawboneから過去と次回の判断IDを突き合わせても、8,274件すべてについて矛盾のない研究日が得られない。
- 現時点で利用可能な公開資料だけから、2019年解析用7,540/6,061件の全除外を一意に再構築できていない。

**科学的な結論**：「現在の公開資料と手法では完全再現が未達」。非公開データを無断利用しない。原因が誰にも永久に解けないとは主張しない。H005は**ユーザー承認のスコープ削減によるskip**であり、失敗が成功に変わったわけではない。

## H006〜H010の受け入れ条件の変更

- **H006:** 公開CSVの介入可能な判断時点について、件数、送信別頻度、歩数の平均・SD・欠測を再計算。
- **H007:** 37参加者というクラスタ構造を扱い、独立同分布を仮定した単純標準誤差のみで分析しない。
- **H008:** 通知あり/なしと歩行通知の比率および95%CIを**探索的な関連**として出す。論文差と方法差を併記。
- **H009:** 実際にある決定順序インデックスによる時系列上の関連変化を、**研究日の代用としない**ままモデル化・95%CI報告。
- **H010:** ソース版、SHA、選別ルール、限界、指標、実行テストと再現手順を公開。個別参加者データは成果物に残さない。

**技術面の到達点**は、公開研究データについて「入力の再現可能性→解析対象の検証→統計モデル→CI→元研究との差の監査」というループを実装したこと。**Gate 1の独立したRCT効果再現は、H005がskipのため未達のまま。** Phase 04/ベンチマークの後続で別の権利・解析条件が明確な公開RCTを使用する必要がある。

## 学び・Managerへの設計反映

1. シミュレーションと実験は違うだけでなく、**公開CSVの版と論文の解析母集団も別**になりうる。
2. 予測の高精度や比率の一致より、**再現可能な選別ルールと否定的検証結果**が重要。
3. 同じ人の観測が多数含まれるときは、**参加者クラスタ単位**で誤差を扱う。
4. 欠測ゼロ補完と本当のゼロは違う。`jbsteps30.zero`を使う推定には限界がある。
5. 機械学習やAIによる介入選択では、**データ対応が不明なら原研究の正確な効果を断定しない**。
6. 公益目的でも、個人データの利用許諾と本番介入の権限を勝手に推測しない。
