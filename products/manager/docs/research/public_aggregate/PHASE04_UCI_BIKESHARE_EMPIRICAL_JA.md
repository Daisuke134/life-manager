# Manager Phase 04 — 公開実測・年次外部検証（UCI Bike Sharing）

**研究日:** 2026-10-21 JST  
**判定:** 観測された **集計されたレンタル数** の年次外部検証に成功。**SocSci210の個人行動予測でも、人間シミュレーションの因果忠実度検証でもない。**

## 1. 何を実際に確かめたか

公開されているワシントンDCの自転車レンタル日次集計について、2011年の365日で**一度だけ**パラメータを決め、時間的に後の2012年366日を完全な評価対象として固定した。未来のラベルや2012年の結果を用いて学習しない。2012年の冬91日と夏94日も、それぞれの結果を別に表示する。

- 集計単位は「1日の全レンタル数」。「人」でも「無作為化の介入時点」でもない。
- **正解ラベル:** その日のレンタル数が2011年トレーニング期間の中央値以上なら1、それ以外0。しきい値は評価年の観測を見る前に確定。
- 学習に使える変数は季節のみ。天気・日数経過・2012年の成果・casualやregisteredの将来値を入力していない。
- **学習モデル:** 全年一律の発生頻度、訓練時の多数決、2011年の季節別平均・季節別比率。複雑なLLMではなく、誤魔化しにくい基準線を置く。
- **評価:** 予測分類の正答率、確率二乗誤差(Brier)、予測割合と実際の割合のTVD、1日の総台数の平均絶対誤差(MAE)。さらに週単位のブロック再標本化によるMAE差の不確実性。

## 3. 実際の2012年データに対する結果

実行 [GitHub Actions 39545601251](https://github.com/Daisuke134/life-manager/actions/runs/39545601251) の**ピン留め実測CSV**から計算された数字。構築した架空回答の結果ではない。

| モデル | 正答率 | Brier（小さいほど良い） | TVD（小さいほど良い） | 日次台数MAE（小さいほど良い） |
|---|---:|---:|---:|---:|
| 2011年頻度を固定 | 83.33% | 0.2491 | 0.3320 | 2,488.67台 |
| 2011年多数派を固定 | 83.33% | 0.1667 | 0.1667 | 2,488.67台 |
| 2011年季節別平均を固定 | 65.30% | 0.2167 | 0.3333 | **2,303.65台** |

注意：多数派は予測確率が常に1のため、2012年に多数が高需要になった場合の正答率が高い。しかし、2011年に決めた基準線が「需要の高まり」を早期に予測できたことにはならない。確率誤差・集計バイアス・レンタル台数の誤差は**同じ指標ではない**。

**実測 MAE 差:** 全年平均を使う方法 2,488.67台 − 季節別 2,303.65台 = **185.02台/日**。ただし、2012年の時間的依存を考慮した同一日ペアの**7日ブロック・ブートストラップ600回**による差の95%区間は **[-50.30, 391.18] 台/日**（乱数種固定）。**0を跨ぐ**ので、この計算だけで季節別法が一貫して優れるとは断定できない。これは観測予測誤差の区間であり、因果的な介入効果の区間ではない。

**二つの未使用評価条件（いずれも2012年、学習年と時系列で完全分離）**

| 条件 | 日数 | 季節別確率Brier | 季節別TVD | 季節別の台数MAE |
|---|---:|---:|---:|---:|
| 冬（winter_2012） | 91 | **0.45055** | 0.45055 | 1,940.56台 |
| 夏（summer_2012） | 94 | **0.01913** | 0.13830 | 2,368.32台 |

夏の二値指標の正答率は100%だが冬は54.95%。**まとめた正答率だけ見ると外挿性能の失敗を隠す**。2012年に平均需要が高まったという年次分布変化のもとでの結果であり、未知の参加者への一般化や、別都市への外挿ではない。2011年の冬と夏自体は学習に登場しているため、これは「新しい季節ラベルへの外挿」ではなく**未知年・既知季節という二つの新しい時間環境**の検証である。

## 4. 論文や既存の合成データとは何が違うか

- これは **観測済みの日次集計** の予測/事後採点。HeartStepsの無作為化試験でもSocSci210の210研究でもなく、介入の `do(X)` 結果は測れない。
- 別の `phase04_synthetic.py` は、`P(Y=1|do(0))=0.3`, `P(Y=1|do(1))=0.7` を人工的に置き、周辺分布TVD=0でも介入効果差0.4の**論理的反例**が構築できることを示す。この0.4は実在の人間に対する推定ではない。
- 生成モデルが特定の人間を再現する能力、心理的損害や健康改善、政策介入の純効果、社会的厚生、実世界の受益者、シミュレーションの因果忠実度については、この自転車データから肯定しない。

## 5. 続きの科学上の必須条件

**SocSci210:** 170学習研究/40未見研究の権利確認済み**研究IDだけ**保持。原研究別の参加者回答データのライセンス、同意、データ処理条件は依然HOLD。40研究の本物のaccuracy/TVD、同じ分割での公開学習済みモデル比較と推論コスト、被験者サブグループ評価はいずれも**未実施**。ユーザーによる包括的な作業承認は元の研究参加者の許諾を代理しない。

**Concordia:** 正規上流パッケージを使ったESA形式の**架空のエージェント**と、現実の独立検証は必ず別の領域で保存する。モックの日本語/JSON変換警告等、実行ログ上の問題を隠さない。これは社会モデルの精度評価ではない。

**Gate 1:** 過去のRCTの独立した因果効果の再現、または正当な新しい公開RCTによる代替検証は未達。**Managerによる社会・個人の苦しみの減少は未測定。**

## 6. 再現と品質上の制約

```bash
cd products/manager
python3 -m unittest tests/test_phase04_bike_sharing.py -v
python3 scripts/phase04_bike_sharing.py --output output/phase04-public-aggregate
python3 -m unittest discover -s tests -v
python3 scripts/check_boundaries.py
python3 scripts/make_roadmap.py --check
```

- 日次生データは実行時メモリのみ。CIはハッシュ・列構造・日次集計整合性・学習/評価年が重ならないことをチェックし、匿名性の過剰な保証はしない。
- スナップショット差異、想定外の列、不整合な集計、2011/2012以外の期間、2012にしかない季節、出典不一致、複数実行の条件違いには**fail closed**。
- 信頼区間はブロック・ブートストラップの探索的近似で、予測性能の厳密な将来保証ではない。観測の独立性/定常性などの前提が違えば精度が変わる。
- 元データクレジットと帰属表示は再利用物に保持。原論文・個票の再配布権を推測しない。
