## Cross-repository connections that matter

**1. Inspect AI × JudgeBench × Hamel Husain:** The evaluated model, evaluator, and evaluator-of-the-evaluator are separate entities. Instrument errors, order bias, threshold selection and human-label disagreement all require explicit accounting. [Hamel/Saha](https://hamel.dev/blog/posts/decision-model-evals/) compared six classifiers on 100 human-labelled traces; F1 at a default 0.5 threshold should not be extrapolated to other tasks without recalibration.

**2. SWE-bench × Browser Use audit:** The evaluator itself must be adversarially tested. Correct gold passes, null/perturbed/wrong gold fails, did the suite run, was the environment reset, are individual cases independently held out, and can the agent retrieve answers through the web or repo? Test answers must be structurally inaccessible to the model under improvement.

**3. τ²-bench × WebArena × EBA:** Final DB state, tool calls and communication may disagree. A support navigator might produce a pretty answer, but the actual link could be broken; the link could work, but users might not find it; users might find it, but this could produce **no net wellbeing benefit**. Grade all four things *separately*.

**4. OmniBehavior × Simile × Aaru:** Different metric targets: next user action F1/logloss, survey distribution TVD, and predicted error of survey simulation. A regression benchmark cannot inherit a published survey error-rate as a baseline. Isolate users, study, time and cohort before comparing any numbers.

**5. Open Bandit Pipeline × field trials:** Logged propensities and no interference assumptions must be justified before offline policy evaluation. If old policy never offered an action to a subpopulation, no estimator can know the effect of that unseen action without further valid information. A randomized future trial and independent outcome collection remains the direct option in many settings.

## What was NOT done

No upstream code was executed, model checkpoints downloaded, person-level datasets redistributed, permissionless third-party world intervention performed, private GitHub repository inspected, or original published benchmark score reproduced by reading these files. We have studied selected **actual source code**, not cloned and run all upstream projects. A no-contact public repository cannot substitute for informed consent to a human health/welfare experiment.

The broader [benchmark atlas](EVAL_LANDSCAPE_20261022.json) lists **90 named systems** across **14 categories**, separating true benchmark, runner, field study, data and outcome instruments. Inclusion is not endorsement or evidence of replicability; verify version, URL, license and task implementation before integration.
