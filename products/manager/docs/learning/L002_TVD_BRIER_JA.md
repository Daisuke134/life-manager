# L002 — TVDとBrier score：人間行動予測をどう評価するか

**Manager / Phase 02 / 2026-10-20 / learning + offline code only**

L001では `P(Y|X)`（状況が与えられたとき行動する確率）を計算した。L002では、その**予測の誤差**を評価する。ここで使う値は**すべて架空**。本物の参加者データを取得したわけではなく、Managerの介入による成果でもない。

## 1. TVD：集団全体の回答分布のズレ

AIによる商品A購入予測は70%、現実の実測率は50%、購入しない確率はそれぞれ30%と50%だとする（架空例）。

| 選択肢 | AI予測 P | 観測 Q | 絶対差 |
| --- | ---: | ---: | ---: |
| 商品Aを買う | 0.70 | 0.50 | 0.20 |
| 買わない | 0.30 | 0.50 | 0.20 |

`TVD(P,Q) = (|0.70-0.50| + |0.30-0.50|)/2 = 0.20`。

TVDは `0` が集団分布の一致、`1` が離散的な分布の最大不一致。ラベル集合が片方にしかない場合も、確率 `0` として合算する。集団のサンプル数、集計方法、同時期性を確認しなければ、その数値の信頼性を判定できない。

出典：[Simile: Building confidence in Simile](https://www.simile.com/blog/confidence)（企業がTVDを使った予測分布の誤差評価と、誤差そのものの予測を説明。企業本人の記述であり、Managerによる独立再現ではない）。

## 2. Brier score：一つ一つの確率予測の誤差

二値結果 `y_i`（起きた=1、起きなかった=0）と、**対応する個別予測確率** `p_i` のペアが必要。

`Brier = (1/N) * sum_i (p_i - y_i)^2`。

- 予測 `p = [0.9, 0.1]`、実際 `y = [1, 0]` → `(0.1²+0.1²)/2=0.01`（良い）。
- **同じ**予測 `p = [0.9, 0.1]`、実際 `y = [0, 1]` → `(0.9²+0.9²)/2=0.81`（悪い）。
- どの対象にも `0.5` と予測すると、二値結果ではBrierは必ず `0.25`。ただし「常に0.5が妥当」という意味ではない。

重要：上の2例は、平均予測確率がいずれも50%、実際の陽性率も50%。したがって**集団集計で見ればどちらもTVD=0**だが、個別Brierは`0.01`と`0.81`で極端に違う。集団の割合が合うことは、誰の行動を当てたかを保証しない。

出典：[scikit-learn: brier_score_loss](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.brier_score_loss.html)。二値Brierでは0が最良、1が最悪。公式例 `p=[0.1,0.9,0.8,0.3], y=[0,1,1,0]` は `0.0375`。

## 3. 何が評価できて、何ができない？

| 項目 | TVD | Binary Brier |
| --- | --- | --- |
| 何を比較？ | 予測と観測の**集団回答分布** | 各ケースの確率とその**観測された二値結果** |
| 値の目安 | 0=完全一致、1=最大不一致 | 0=完全一致、1=最大の外れ（平均） |
| 主な強み | 市場・政策アンケートなどの割合比較 | 個人別・事例別に確率の正確さを評価 |
| 主な弱み | 個別の対応を当てたかは分からない | 個々の正解ペアが必要。単一のスコアだけで校正は分からない |
| ここから推定できないもの | 介入した場合の**因果効果** | 介入した場合の**因果効果** |

さらに、スコアを訓練データ上で計算しても未知の人・条件への汎化を示せない。L003で「予測確率の校正」とholdoutデータを扱う。時系列・同一人物からの反復・サンプル数・少数集団への悪影響はこの簡易教材では未評価。

## 5. Managerへの接続
