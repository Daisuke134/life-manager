# L012 — 「何が証明されたか」を誇張しない証拠階層

出典の背景：HeartSteps https://pmc.ncbi.nlm.nih.gov/articles/PMC6401341/ ; intervention review https://pmc.ncbi.nlm.nih.gov/articles/PMC5364076/ ; causal identification https://miguelhernan.org/whatifbook

| Level | 合格に必要な情報 | この段階だけでは主張できないこと |
|---|---|---|
| P0 | 研究、仮説、予測、シミュレーションだけ | 実際の介入が行われたとは言えない |
| P1 | 独立した公開実行receipt（権限と一致） | 状態変化・便益は未確認 |
| P2 | 外部の独立計測で現実の変化を確認 | 利益や健康改善は未確認 |
| P3 | 実際の受益者への有形の便益を測定 | 比較対象がなく因果効果を主張できない |
| P4 | 事前登録の比較、効果と不確実性、費用・害の把握を満たす | 対象外人口への一般化は未確認 |
| P5 | 実質的に異なる集団・領域で効果を再現 | 世界中の苦しみが終わった証拠ではない |

重要：クリック、公開TX、予測TVD、実行ログ、空気清浄機のONは**どれも単独では苦しみの低減を証明しない**。負の効果と未測定も明記する。

`manager_core/outcome_ladder.py`は上記に必要な証拠フラグの存在と依存順のみ機械判定する。入力されたフラグが真実か、RCTが厳密か、当事者の苦しみが実際に減ったかを自動認証する**科学的な審査装置ではない**。Managerの現在の実世界成果は P0 のまま。
