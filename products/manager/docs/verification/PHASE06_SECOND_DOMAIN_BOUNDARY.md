## Authority and independence

| Dimension | Established within the recorded scope | Not established |
|---|---|---|
| Ownership | Bounded Manager publication under the existing owner's `manager-support/` release scope | Authority over MHLW/FSA sites, accounts, clinical services, private records or indoor facilities |
| Shared publisher | One source catalog/renderer, six HTML pages, one manifest, one existing Pages deployment path | Independently controlled second publisher, independent grant/revocation service or separate budget execution |
| Different topics | Finance, mental-support and physical-information pages contain distinct official-source routes | Distinct enrolled populations, random allocation, independent clinical/financial interventions or replication |
| Independent artifact observation | Read-only public response/hash verification separate from the write step | Independent human outcome ascertainment or causal identification |
| Browser evidence | Public Chromium/Chromium mobile-emulation tests, navigation/href checks and accessibility assertions | Human task completion, screen-reader validation, physical-device Safari testing, support receipt or clinical effect |
| Public information | Link-only access to official guidance | Program availability for a particular person, eligibility, accepted referral or treatment |

No NPO agreement or indoor-owner permission is needed for a routine update on an already authorized owned static surface. That fact does not give Manager authority to conduct a human study or change a facility. Optional consented research has its own [collaboration](../../pilot/PUBLIC_AGGREGATE_COLLABORATION_PROTOCOL.md) and [safety](../../pilot/SECOND_DIGITAL_ENVIRONMENT_SAFETY.md) proposals; they are not new per-run release approvals.

## Evidence still absent

There is no actual mental/physical participant cohort, consented response set, observed baseline/follow-up instrument, valid human comparator, measured effect, confidence interval, harms rate, attrition estimate, cost allocation or independent field replication. `real_participants=0` in the release manifest means no enrolled experiment; it does not mean zero public visitors. Actual outcome sample size is **null**, because no outcome dataset exists. No analytics-derived visitor count is supplied.

The [second-domain outcomes](PHASE06_SECOND_DOMAIN_OUTCOMES.md) and [cross-domain field-causal report](PHASE06_CROSS_DOMAIN_FIELD_CAUSAL.md) express these absences without manufacturing values. WHO-5, WHODAS, financial JPY and technical checks remain different measurement families. Their units are not combined into a universal improvement score.

Original F007 concerns real indoor authority, and F008 concerns a real environmental intervention and measurement. An accessible physical-information page supplies neither. The same-registry scope-amendment proposal remains a separate governance decision; this document does not apply it or mark either task complete.
