# Behavior transformation safety v1 — definition proposal

2026-10-23 UTC。**Protocol ID: `MGR-D015-BEHAVIOR-SAFETY-V1`。PRIVATE_DEFINITION_PROPOSAL / SOURCE_NOT_ADOPTED / INDEPENDENT_DESIGN_APPLICABILITY_REVIEW_PENDING / FIELD_NOT_ACTIVATED。**

## 1. Scopeと既存根拠

本人が選ぶ一つの行動について短い説明・任意の実践・振り返りを検討する、将来の非clinical成人研究の保護定義。使命は「行動変容を通じて、苦しみを終わらせることを目指す」。宗教的同意、従順さ、会話長、利用時間、達成率を本人の価値や成功そのものにしない。不調や生活機能の悪化を必要な成長・正しい修行と断定しない。

[新規U004草案](BEHAVIOR_TRANSFORMATION_STUDY_V2.md)は **DRAFT / NOT_REGISTERED / participants=0 / intervention_runs=0**。対象/需要、測定権利、人数/追跡、媒体、同意、実役割、独立観測/停止・支援経路、登録/開始前固定の空欄を保持する。本案は実研究開始、モデル採用、clinical/user safety承認、D015受入を行わない。clinical仮説は適切な専門家/実研究条件へ分離する。

凍結済み[MGR-D015-SAFETY-20261023-v2](MENTAL_OUTCOME_SAFETY_AND_INDEPENDENT_REVIEW.md) §2–6の任意性・撤回・通常支援保持・UNKNOWN・独立判断・非自動復帰を再利用する。旧navigation研究の連絡日、件数/割合/時限triggerや臨床閾値を本研究へ移植しない。旧2protocolと[旧manifest](RESEARCH_PROTOCOLS_20261022.sha256)は全文bytesで保持する。

[既存scopeの介入研究整理](../docs/specs/2026-10-23-behavior-transformation-scope-amendment.md)のguided/package/population/害観測の限界を保持する。Brittonらの不快経験と負の生活機能影響の区別は設計上の参照で、率やinterviewを新しい自動診断/validated screenにしない。[INTIMAの既存用途](../docs/plans/2026-10-23-intima-intake.md)はsyntheticな英語single-turnで圧力・孤立・関係代替等を調べる診断であり、実依存率・本人の心理状態・長期安全性の証明ではない。prompt原文や尺度項目は転載しない。

no UIは通常活動のための専用app/chat・毎回の操作を必須にしない現定義を保つ。同意/目標変更/撤回、監査、停止の入口は実研究で本人が選び成立した媒体に保持できる。新しいUI/通知/監視/外部接触・model/runtimeは追加しない。既公表非個人集計を読む[Step-by-Step offline audit](STEP_BY_STEP_PUBLISHED_EFFECT_AUDIT_V1.md)は別scopeで、そこへ本人monitoring・再同意・clinical staff/IRBを一律追加しない。

## 2. 観測規則と基本動作

下表のsignalは診断ではなく保護のための申告/内容/手続の観測である。本人が許可した研究経路で明示した希望/経験、または許可された実施者が確認した具体的な研究content・同意違反等を根拠にする。利用時間、会話回数、文章の調子、検索/個人属性、modelの内的推定から依存・悪化・同意・危険性を認定しない。AIを好む、頻繁に使う、他人と異なる選択をするだけで依存と扱わない。

現在はsignal取得/monitoring自体を実施していない。将来のU004で本人が受け入れる観測方法/負担/連絡上限/欠測/停止入口を具体化する。本人の私的発言・履歴・診断推定をManagerへ送らず、正当な実研究経路で扱い、Managerには既存同意/公開集計境界に沿う最小の公開可能なdispositionだけを渡す。無回答はUNKNOWNで、安全/改善/同意の肯定ではない。欠測を減らすため拒否や撤回を越えて追跡しない。

signal把握時は因果関係や有意差の確定を待たず、関係する研究固有の作用/接触を止める。通常の支援・医療・生活上の選択は止めない。本人だけの停止と共通content/条件の停止を区別し、共通原因が疑われる場合は該当部分の新曝露も保留する。停止に追加説明/測定への回答を義務付けない。

## 4. 独立した適用判断 — 定義reviewと実場面の区別

**本案のfresh独立design applicability reviewはPENDING、reviewer/receipt/受入UTCは未記録。** author自身の説明を独立判定済みとしない。AI technical design reviewが確認できるのはsignalの観測可能性、停止/支援/復旧の整合、scope/権利/UNKNOWN、実装限界である。個人のuser safety、clinicalな再開可否、法的/IRB承認や免除を代行しない。

有限reviewのchecklistは、各signalを診断/率の推論にしていないか、拒否/無反応を尊重するか、作用を止め通常支援を維持するか、依存/委譲/支援遮断が具体的か、不明はNO_ACTIONか、clinical仮説を必要な実専門条件へ分離したか、復旧が未実判断/本人の選択/版固定を飛ばしていないか、offline読書へhuman gateを広げていないか、未任命/未実施を創作していないか、である。rootが手配する別reviewの実receiptへ結ぶ。

将来の実場面には当該population/内容/懸念に適した専門性と責任を持ち、成功/shipping利害を開示し、必要に応じ作用を止められる実在の独立判断経路が必要。現在は未任命/未成立。clinicalを要する懸念は適した専門的実条件へ分離する。全非clinical定義への一律clinical staff/NDAを加えず、AIに本人のclinical/user safetyを自己認証させない。

実研究側はsignal、把握/停止/判断時刻、未確定の関係、通常支援保持、訂正理由、本人の同意/連絡範囲、disposition、変更versionを正当に扱える場所へ記録する。Managerは私的事例を受け取らず、許可された最小disposition/公開可能集計・provenanceを扱う。missing/withdrawal/不明を改善した人だけの分母から落とさない。

## 5. 実研究開始と復旧に残る条件

実対象/本人の目標、通常支援、断り方、同意/測定/連絡範囲はU004で未確定。実施責任者、適した独立判断、監視される停止/相談/支援経路と稼働条件は未任命/未確認。必要な同意/測定権利/privacy/制度適用、比較/主要結果/追跡/害/負担/欠測/検出力、content/model版、作用停止/訂正/再開権限、登録/開始前固定は現v2の未成立欄を維持する。正式承認/免除・clinical安全性を取得済みとしない。

復旧は停止理由/影響範囲の確認、適した実独立判断、必要な訂正/支援と同意/権利の実確認、本人の自由な再選択、変更versionの再曝露前固定が成立してから判断する。解決不能ならSTOPPED、情報/能力不足ならPAUSED_PENDING_INFORMATION/NO_ACTION。RESUME_WITH_CORRECTIONは条件を実確認した記録がある時だけで、自動復帰はない。辞退/撤回を取り消させる連絡を復旧の必須手続にしない。
